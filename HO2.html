Face ID / Touch ID

系统级生物识别为访问加一道锁；无论共享或私人存储，都能安心进入。

核心功能

在一个界面内连接多个 WebDAV 账户，快速切换路径；以极简交互保持高效与清晰。

多路径管理

同时连接家庭 NAS、团队盘与私人网盘；以收藏夹或固定（Pin）保持常用路径触手可及。

清晰的目录与面包屑

层级导航、面包屑、快速回到上级目录；支持按名称、时间、大小排序。

即时操作

重命名、移动、删除、创建文件夹与直链复制；所有变更即刻作用于云端。

轻量预览

根据文件类型进行轻量级信息展示（如缩略图/元信息），不做本地缓存与离线同步。

无广告、无推荐

不引入第三方推荐与埋点，不干扰你的注意力，保持界面的干净与专注。

键盘友好

常用操作提供快捷键，支持 ⌘/Ctrl + K 快速跳转。

安全守护

隐私与掌控，始终在你手中。Purity 仅在本地保存必要的连接配置，不上传、不追踪。

生物识别加锁

支持 Face ID / Touch ID；启动 App 或进入敏感路径时要求验证。

最小化存储

不缓存文件内容；仅保留必要的会话信息与设置，随时可清除。

透明与可控

提供一键导出/重置配置；权限请求前置说明，避免越权访问。

端到端路径管理

所有操作直达你的 WebDAV 服务，不经过中间代理；你与云端的通道更干净。
